# Connect Four - コネクトフォー

モダンでシンプルなデザインのコネクトフォーWebアプリケーション

## 🎮 ゲームモード

### 1. ローカルPVP (Player vs Player)
同じデバイスで2人が交互にプレイ

### 2. オンラインPVP 🌐
**PeerJSを使用したP2P対戦**
- ルームを作成してIDを友達に共有
- ルームIDを入力して参加
- リアルタイムで手を同期
- サーバー不要の完全P2P接続

### 3. PVC (Player vs Computer)
AIと対戦（3段階の難易度）
- **Easy**: ランダム配置
- **Medium**: 基本戦略（勝利・阻止）
- **Hard**: ミニマックスアルゴリズム

## ✨ 主要機能

- 📊 スコア記録（LocalStorage）
- 📜 ゲーム履歴（IndexedDB）
  - 総ゲーム数
  - 勝率統計
  - 最長連勝記録
- 🔊 サウンド効果（Web Audio API）

- 🎨 スムーズなアニメーション

## 🌐 オンラインPVPの使い方

### ホスト側（ルーム作成）
1. 「オンライン」モードを選択
2. 「ルームを作成」ボタンをクリック
3. 表示されたルームIDをコピーして友達に共有

### ゲスト側（ルーム参加）
1. 「オンライン」モードを選択
2. 友達から受け取ったルームIDを入力
3. 「参加」ボタンをクリック

接続が確立されると、リアルタイムで対戦が開始されます！
