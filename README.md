# Connect Four - コネクトフォー

モダンでシンプルなデザインのコネクトフォーWebアプリケーション

## 🎮 機能

- **PVP (Player vs Player)**: ローカルで2人対戦
- **PVC (Player vs Computer)**: AIと対戦
  - Easy: ランダム配置
  - Medium: 基本戦略（勝利阻止）
  - Hard: ミニマックスアルゴリズム
- スコア記録（ローカルストレージ）
- レスポンシブデザイン
- サウンド効果

## 🎨 デザイン

- カラーテーマ: モダンブルー & ビビッドレッド
- グラスモーフィズム効果
- スムーズなアニメーション
- モバイル・タブレット・PC対応

## 🚀 デプロイ

GitHub Pagesで公開可能

## 🛠️ 技術スタック

- HTML5
- CSS3 (Grid, Flexbox, カスタムプロパティ)
- Vanilla JavaScript
- Web Audio API
